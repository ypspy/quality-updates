# 큐레이션 규칙 백테스트

자동 제안 스크립트 `scripts/auto_curate.py`를 사람이 이미 끝낸 분기와 비교한 결과다. 규칙은 2023–2026 본문과 Appendix에서 읽은 패턴에 소유자 확정을 더한 것이다. 가장 최근의 완전 큐레이션 분기인 `2026-04-01_to_2026-06-30.md` 는 채점용이다. 세칙·지속가능성·금감원 중복·한공회 재안내·불공정거래·소유주식·중점 점검·행사·안내에 대한 소유자 확정을 반영한 뒤의 수치다.

콘텐츠 파일은 수정하지 않는다. 마커는 편집기 저장 형식과 같고, 제안의 `pending` 은 실제 PDF·캡처 경로를 아직 모른다는 뜻이다.

## 데이터 형태

- 크롤 원본은 각 분기 파일 말미 `## Appendix A` 에 그대로 있다.
- 본문(Appendix 앞)은 사람이 남긴 항목만 있다. `prepare_deploy.py` 가 `<!-- skip -->` 쌍을 지우므로, 배포된 분기에는 스킵 마커가 없고 **Appendix에만 있는 링크 = 스킵**이다.
- 본문에 `!!! note` 가 있으면 요약(편집기 상태 완료). `<!-- no_summary -->` 또는 마커 없는 링크는 링크만 유지.
- `<!-- source: type|ref -->` 는 2025 Q1과 2026년에 남아 있다. 2023–2024와 2025 Q2–Q4 요약문은 출처 마커 없이 노트만 있는 경우가 많다.
- 본문에만 있고 Appendix에 없는 링크는 수기 추가(시행세칙 등)라 채점에서 뺀다.

## 채점 정의

- 스킵 정밀도·재현율의 양성 클래스는 **스킵**이다.
- 3분류 정확도는 스킵 / 링크만(`no_summary`) / 요약이 모두 맞을 때의 비율이다.
- 출처 정확도는 실제 출처 유형이 남아 있는 항목만 분모로 한다. 유형(`pdf`·`shot`·`clip`·`web`)이 같고 요약으로 제안했을 때 맞춘 것으로 센다. 파일 경로·clip id 는 맞추지 않는다.
- 출처 계열 정확도는 `pdf`(첨부)와 페이지 캡처(`shot`/`clip`/`web`)만 구분한다.

## 읽는 법

- 2023–2024 3분류 정확도가 더 낮으면, 그 시기에는 회계 항목을 노트 없이 링크만 남긴 경우가 많아서다. 최근 관행(2025 이후)은 같은 주제를 요약한다. 규칙은 최근 관행을 따른다.
- 스킵 정밀도가 높고 3분류가 그보다 낮으면, 빠질 기사를 가리는 것보다 **남긴 기사를 요약할지 링크만 둘지**가 더 어렵다.
- 규칙 설명과 사람이 볼 경계 사례는 [curation-rules.md](curation-rules.md)에 있다.
