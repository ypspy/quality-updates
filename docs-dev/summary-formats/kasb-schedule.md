## 1. 목적·범위

| 기관 | 절 |
|------|-----|

스킬 REFERENCE E 「회계기준위원회·지속가능성기준위원회 회의」와 동일하며, 빈 줄·볼드 금지 판정은 이 파일이 SSOT다.

---

## 2. 필수 구조

- 링크 줄 + `!!! note "주요 내용"` + 들여쓰기 4+4.
- note 본문 **헤더** (텍스트 그대로):
  - `□ 의결 안건`
  - `□ 보고 안건`
- **빈 줄 규칙** (SKILL REFERENCE E):
  1. `□ 의결 안건` 다음 **빈 줄 1개**
  2. 의결 안건 불릿 (`- 제○호 …` 등)
  3. **빈 줄 1개**
  4. `□ 보고 안건`
  5. **빈 줄 1개**
  6. 보고 안건 불릿
- 각 안건은 `- 제○호 …` 형태 불릿으로 나열한다.
- **볼드 금지**: 의결·보고 안건 문장 안 **제도명·기준명** 등에 볼드를 쓰지 않는다 (일반 general-note와 다름).
- 해당 회차에 의결 또는 보고 안건이 없으면 그 섹션에 `해당사항 없음` 한 줄을 둔다.
- style-A/B 접두 규칙은 적용하지 않는다 (안건 헤더·호 번호 구조가 스키마다).

## 4. DoD Pass/Fail

| 검사 항목 | Pass | Fail |
|-----------|------|------|
| **Format** | `!!! note "주요 내용"`, 4+4 들여쓰기 | admonition·들여쓰기 오류 |
| **Facts** | 호 번호·안건명·의결 요지가 회의 공고와 일치 | 호 번호 누락·안건명 왜곡 |
| **Tone-detail** | 안건 수에 맞는 간결 불릿 | 원문 안건 전문 복사 |
| **□ 헤더** | `□ 의결 안건` / `□ 보고 안건` 둘 다 존재 (없는 쪽은 `해당사항 없음`) | 헤더 누락·다른 기호 사용 |
| **빈 줄** | REFERENCE E의 1-1-1-1-1 배치 | 헤더 직후 불릿 붙음·섹션 사이 빈 줄 누락 |
| **제도명 볼드** | 안건 문장에 볼드 없음 | `**K-IFRS**` 등 안건명 볼드 |
