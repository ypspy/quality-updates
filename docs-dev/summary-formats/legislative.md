# 입법·예고 note 형식 기준 (legislative, 2026 Q3)

FSS **세칙제ㆍ개정예고**, FSC **입법예고/규정변경예고**의 `!!! note "주요 내용"` DoD다.

---

## 1. 목적·범위

| 기관 | 절 |
|------|-----|
| 금융감독원 | 세칙제ㆍ개정예고 |
| 금융위원회 | 입법예고/규정변경예고 |

일반 보도·고시, 동향자료, 제재, KASB 일정은 이 family가 아니다.

스킬 REFERENCE E의 「입법예고/규정변경예고」와 동일 계열이며, **의견 제출 기한 볼드** 등 판정 기준은 이 파일이 SSOT다.

---

## 2. 필수 구조

- 링크·`!!! note "주요 내용"`·들여쓰기 4+4는 [general-note.md](general-note.md)와 같다.
- **접두어**: legislative는 **style-A (괄호)** 만 사용한다. `(취지)`, `(개정 배경)`, `(주요 내용)`, `(시행)`, `(의견 제출)` 등.
- **필수 내용 축** (원문에 있으면 note에 반드시 반영):
  - 개정 **취지/배경**
  - **주요 내용** (조문·제도 변경 요지)
  - **시행** 시점 또는 일정
  - **의견 제출 기한** — 날짜·기한 문구는 **볼드** (`**…**`)
  - 개정 대상 **법령·규정·시행령·규정명** (원문 표기 유지)
- 외부감사법 관련 개정예고는 내용 누락 없이 요약한다 (스킬 REFERENCE E).
- style-B `**주제**:` 불릿은 이 family에서 쓰지 않는다.

## 4. DoD Pass/Fail

어미(합니다체)는 [README 공통 Format](README.md#공통-리뷰-3축)만 본다.

| 검사 항목 | Pass | Fail |
|-----------|------|------|
| **Format** | style-A 괄호만, note 문법·들여쓰기 준수 | style-B(`**주제**:`) 혼입, admonition 오류 |
| **Facts** | 시행일·기한·조문 요지가 원문과 일치 | 추정 일정, 잘못된 규정명 |
| **Tone-detail** | 불릿 밀도·증류가 Q3 legislative 앵커와 동급 | 원문 조문 나열식 과다 또는 1~2줄 과소 |
| **의견 제출 기한** | 기한·마감일이 **볼드**(`**…**`)로 표시 | 기한이 일반 문장만 있거나 볼드 없음·누락 |
| **법령·규정명** | 개정 대상 명칭이 원문과 동일하게 서술됨 | 규정명 누락·축약 오류 |
