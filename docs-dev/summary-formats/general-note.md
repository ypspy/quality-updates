# 일반 note 형식 기준 (general-note, 2026 Q3)

이 문서는 Q3 골드셋에서 **일반 `!!! note "주요 내용"`** 요약의 작성·리뷰 DoD다.

---

## 1. 목적·범위

| 기관 | 절 |
|------|-----|
| 금융감독원 | 보도자료 |
| 금융위원회 | 보도자료, 고시/공고/훈령 |
| 한국공인회계사회 | 알림마당 - 공지사항, 회계감사 - 감사인증기준 |
| 한국회계기준원 | 소통광장 - 공지사항 |

입법예고·동향자료·제재·KASB 주요일정·`<!-- no_summary -->` 링크는 이 family가 아니다. Q3 밖 타입을 여기 규칙으로 끌어오지 않는다.

블록 문법·들여쓰기·공통 작성 규칙은 스킬 REFERENCE A·B와 같다. 이 파일은 family 전용 판정만 고정한다.

---

## 2. 필수 구조

- 링크 줄: `- (YY-MM-DD) [제목](URL)` (게시일 형식은 분기 관례)
- 요약: `!!! note "주요 내용"` (다른 note 제목은 이 family에서 쓰지 않음)
- **들여쓰기**: 링크 하단 4칸 → admonition, 블록 내용 추가 4칸, admonition 줄과 첫 불릿 사이 빈 줄 1개
- **접두어**: 한 note 블록 안에서는 **style-A XOR style-B** (혼용 금지)
  - **style-A (괄호)**: `(취지)`, `(배경)`, `(개요)` 등 2~6자 괄호 접두 — 서사·개정 흐름·순차 설명
  - **style-B (볼드-콜론)**: `**주제**:` — 점검·유의사항·독립 항목 나열
- **불릿 수**: 보통 3~7개 (짧은 공지 2~3, 긴 문서 8~9 허용)
- **어미**: 명사형 / `~함` / `~임` / `~예정` (합니다체·음슴체 금지)
- **볼드**: 핵심 제도명·기준치·기한 등 키워드에만; 불릿 전체를 볼드로 감싸지 않음
- 요약 블록 안 **URL 없음** (출처는 HTML `<!-- source: … -->`만)

### A vs B 선택

| 원문 성격 | 스타일 |
|-----------|--------|
| 점검결과·유의사항·체크리스트형 나열 | **B** |
| 배경 → 조치 → 향후 등 서사·개정 흐름 | **A** |

한 링크 note에서 A 불릿과 B 불릿을 섞으면 Fail이다.

## 3. 모범 앵커

전문 복붙은 `gold-excerpts`를 연다. Q3 본문에서 제목 키만 확인한다.

| 스타일 | 대표 앵커 (Q3) |
|--------|----------------|
| style-B | `(26-09-03)` 감사전 재무제표 제출 위반 점검결과 및 유의사항 안내 |
| style-A | `(26-09-23)` 토지 공시지가 인식 관련 주석 공시 유의사항 안내 |

경로: `docs/quality-updates/2026/2026-07-01_to_2026-09-30.md` — 위 날짜·제목 키로 검색.

발췌 ID(갱신 시): E2 = style-B, E1 = style-A (`gold-excerpts.md` 표 참고).

## 4. DoD Pass/Fail

| 검사 항목 | Pass | Fail |
|-----------|------|------|
| **Format** | `!!! note "주요 내용"`, 4+4 들여쓰기, 블록 내 접두어 일관 | B1 혼용, 잘못된 admonition·들여쓰기, note 안 URL |
| **Facts** | 수치·날짜·대상이 PDF/원문과 일치 | 추정·반올림·원문 없는 사실 |
| **Tone-detail** | 3~7 불릿(예외 범위 준수), 증류 수준이 앵커와 동급 | 원문 장문 재현, 1~2 불릿 과소 또는 장황 과다 |
| **A/B 일관성** | 블록 전체가 A 또는 B 중 하나 | 동일 note에 `(…)` 와 `**…**:` 혼재 |

---

## 5. 비범위

- **legislative** (세칙·입법·규정변경예고)
- **trend-briefing** (회계감독 동향자료, 다중 source + 개요)
- **sanctions** (`제재 의결`)
- **kasb-schedule** (KASB 주요일정 `□ 의결` / `□ 보고`)
- `<!-- no_summary -->` 링크
- nested-info(지적사례 접기)·중대 부정 서술 블록 등 Q3 미출현 특수 유형(기존 스킬 REFERENCE E는 참고만)
