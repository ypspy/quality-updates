# 제재 의사록·안건 다운로드

파일 이름은 `README.md`이다. 금융위원회는 2001-01-26부터, 증권선물위원회는 2001-02-08부터, 임시회의와 서면회의를 포함한 모든 회차를 담는다. 사이트에 없는 회차는 만들지 않는다.

## 폴더

- 정기: `{연도}-{위원회}-{N}차/`
- 임시·서면: `{연도}-{위원회}-{임시|서면}-{N}차/`

## 보존

- 의사록 PDF
- 조사·감리 공개용 안건 PDF와 의결서 PDF

## 제외

- 회의결과만 있는 글. 남길 PDF가 없는 회차는 폴더를 만들지 않는다.
- ZIP 원본
- HWP, HWPX, XLS, XLSX. PDF가 아닌 의사록은 변환하지 않고 `_pending-conversion.jsonl`에만 적는다.
- 불공정거래, 시세조종, 미공개정보, 규정 개정
- 비공개기간 경과 안건(연말 일괄 공개, 회차 없음)
- 시장질서교란 의결서·안건

## 실패 목록

실패는 `downloads/sanctions/_failed-downloads.jsonl`에 남긴다. 끝난 글과 페이지는 `_backfill-state.json`에 남긴다. 이 목록과 회차 원문은 저장소에 커밋하지 않는다.
