# 제재 의사록·안건 다운로드

파일 이름은 `README.md`이다. 금융위원회는 2001-01-26부터, 증권선물위원회는 2001-02-08부터, 임시회의와 서면회의를 포함한 모든 회차를 담는다. 사이트에 없는 회차는 만들지 않는다.

## 폴더

- 정기: `{연도}-{위원회}-{N}차/`
- 임시·서면: `{연도}-{위원회}-{임시|서면}-{N}차/`

## 회차 판정

- 의사록 PDF는 글 게시일이 아니라 PDF 첫 쪽의 회의일과 제목(위원회·임시·서면·회차)으로 폴더를 정한다.
- 회의일을 못 읽으면 파일명의 연도(`2015-제5차 …`)를, 그것도 없으면 글의 회차를 쓴다.
- 옛 글처럼 여러 해의 같은 회차 의사록을 한 글에 묶은 경우, 회의일을 못 읽은 PDF는 글 날짜 폴더에 두지 않고 `_review/{글번호}/`에 두고 `_review-queue.jsonl`에 적는다.
- 묶음이 아닌 글이라도 1월 1일부터 90일 안에 올라온 글에서 회의일과 파일명 연도를 모두 못 읽은 의사록은 지난해 12월 회의일 수 있으므로 글 연도 폴더에 두지 않고 검토로 보낸다(`undated-early-year-post`, `candidate_folder`는 글의 회차 폴더).
- 그 밖의 묶음이 아닌 글에서 회의일을 못 읽어 글의 회차로 둔 의사록은 실행 보고에 `undated-post-fallback {위원회} {글번호} {파일명} -> {폴더}/{파일}`로 한 줄씩 남긴다. 조용히 글 연도로 떨어뜨리지 않는다.
- ZIP은 회의가 하나로 정해진 글에서만 그 회의 폴더에 푼다. 여러 해 묶음 글의 ZIP(`zip-in-multi-year-bundle`)과, 의사록이 있었지만 한 회의로 정해지지 않은 글의 ZIP(`zip-without-single-meeting`)은 풀지 않고 원본째 `_review/{글번호}/`에 두고 `_review-queue.jsonl`에 적는다.
- 같은 회의 폴더에 같은 파일(sha256)이 있으면 다시 두지 않는다. 다른 파일이 있으면 덮어쓰지 않고 검토로 보낸다.
- 파일명에 다른 해가 적힌 HWP 의사록은 버리지 않고 `_pending-conversion.jsonl`에 그 해의 `meeting_folder`와 함께 적는다. 받지는 않는다.

## 보존

- 의사록 PDF
- 조사·감리 공개용 안건 PDF와 의결서 PDF

## 제외

- 회의결과만 있는 글. 남길 PDF가 없는 회차는 폴더를 만들지 않는다.
- ZIP 원본(검토로 보낸 ZIP은 `_review/`에만 원본째 남는다)
- HWP, HWPX, XLS, XLSX. PDF가 아닌 의사록은 변환하지 않고 `_pending-conversion.jsonl`에만 적는다.
- 불공정거래, 시세조종, 미공개정보, 규정 개정
- 비공개기간 경과 안건(연말 일괄 공개, 회차 없음)
- 시장질서교란 의결서·안건

## 실패 목록

실패는 `downloads/sanctions/_failed-downloads.jsonl`에 남긴다. 검토 대기는 `_review-queue.jsonl`과 `_review/`에 남긴다. 끝난 글과 페이지는 `_backfill-state.json`에 남긴다. 이 목록과 회차 원문은 저장소에 커밋하지 않는다.
